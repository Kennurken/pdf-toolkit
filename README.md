# PDF Toolkit CLI

Small command-line tool for repetitive PDF paperwork: merge, split by page ranges, diagonal watermark, and fill AcroForm fields from a CSV (one output PDF per row).

## How to run

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# from this directory
python -m pdftool merge sample_files/page_a.pdf sample_files/page_b.pdf -o /tmp/merged.pdf
python -m pdftool split sample_files/multi.pdf --ranges 1-2,3- -o /tmp/split_out/
python -m pdftool watermark sample_files/multi.pdf --text DRAFT -o /tmp/draft.pdf
python -m pdftool fill sample_files/intake_form.pdf --data sample_files/sample_data.csv -o /tmp/filled/
```

Sample PDFs under `sample_files/` are generated by `python sample_files/build_samples.py` if you need to recreate them.

## Examples

Merge two files in order:

```bash
python -m pdftool merge a.pdf b.pdf -o combined.pdf
```

Split pages 1–3, 4–6, and the rest from page 7:

```bash
python -m pdftool split report.pdf --ranges 1-3,4-6,7- -o parts/
```

Watermark (optional `--font-size` / `--opacity`):

```bash
python -m pdftool watermark contract.pdf --text CONFIDENTIAL --opacity 0.2 -o out.pdf
```

Fill a form PDF — CSV headers that match field names are written; extra columns
are ignored, and form fields not present in the CSV stay blank:

```bash
python -m pdftool fill intake_form.pdf --data clients.csv -o filled/
```

If the template has no AcroForm fields, the command exits with a clear error instead of writing broken files.

## Known limitations

- Page ranges are 1-based and inclusive. `7-` means page 7 through the last page.
- Watermark is a flat text stamp (not an optional PDF optional-content layer).
- Form fill relies on AcroForm field names; XFA-only forms are not supported.
- Appearance of filled fields depends on the PDF viewer honoring `/NeedAppearances`.
